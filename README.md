# MagicWeb 🪄

This repository is developed based on our team project—a responsive web application showcasing themed card collections from **Spider-Man**, **The Lord of the Rings**, and **Final Fantasy**.

> 🔄 **Note / Refactoring Updates**:
> All individual feature branches (`spidermanCardPage`, `El-Senyor-dels-Anells`, and `final-fantasy-`) have been consolidated into the `main` branch, alongside code review, bug fixes, and performance optimizations.
